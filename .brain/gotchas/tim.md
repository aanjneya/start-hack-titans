# Gotchas (tim)

- **brain-push.sh false "overlapping edits" conflict on Windows** (2026-11-21): with `core.autocrlf=true` the temp worktree checks files out as CRLF while the merge base (`git show HEAD:`) is LF, so `git merge-file` sees every line changed. Workaround: convert the edited file to LF (`sed -i "s/\r$//" <file>`) and run `GIT_CONFIG_COUNT=1 GIT_CONFIG_KEY_0=core.autocrlf GIT_CONFIG_VALUE_0=false ./scripts/brain-push.sh "<msg>"`. Real fix: normalize EOL in the script or add `.gitattributes` with `*.md text eol=lf`.
- **Claude key in `.env` never reached the SDK** (20:30): `core/llm.py` called `anthropic.Anthropic()`, which only reads real env vars; `.env` is parsed into `Settings`, not exported. Every non-mock Claude call failed with "Could not resolve authentication method". Fix (branch `tim`, eb48d41): `Settings.anthropic_api_key` + `Anthropic(api_key=...)`.
- **Windows: tests + verify.sh** (20:50): `ZoneInfoNotFoundError: Europe/Berlin` -> `pip install tzdata` (added to requirements on `tim`). 4 `test_ingest_watcher.py` tests still fail on Windows (paths with `\` vs `/`). `verify.sh` (and the pre-push hook on `main`) fails at "Checking Python syntax" because `python3` is the MS-Store stub. Don't bypass the hook: put a shim first on PATH, e.g. a file `python3` with `#!/bin/sh` + `exec /c/Users/<you>/start-hack-titans/backend/.venv/Scripts/python "$@"`, then `PATH="/c/<shim-dir>:$PATH" git push origin main` (use `/c/...`, not `C:/...`, or the colon breaks PATH).
