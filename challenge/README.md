# Challenge Materials — START Hack Munich

Drop everything received from **START Hack Munich** and challenge sponsors into this folder:
- Challenge briefs & problem statements (`.md`, `.pdf`, `.txt`)
- Judging criteria & rubrics
- Sponsor API docs, starter kits, or sample payloads
- Small sample datasets or schemas

> [!WARNING]
> **Keep large raw datasets (>25MB) out of Git.** For large files, store them locally (and add them to `.gitignore`) or share via Drive/cloud link documented in a `.md` file here.

## Sync Rule
Whenever any teammate adds new challenge briefs or sponsor docs here, commit and push `challenge/` directly to `main` (just like `.brain/`) so all 4 teammates and their agents immediately share the exact same ground-truth requirements.
